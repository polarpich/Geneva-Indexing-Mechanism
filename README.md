## ภาพรวมของกลไก

Geneva Indexing Mechanism ใช้หมุด (pin) บนจานขับ (driving wheel) เข้าไปขับร่อง (slot) ของจานตาม (Geneva wheel) ทำให้จานตามหมุนทีละช่วงและหยุดนิ่งสลับกันไป

**คุณลักษณะสำคัญ**

1. เปลี่ยนการหมุนต่อเนื่องให้เป็นการหมุนแบบไม่ต่อเนื่อง
2. มีช่วงหยุดนิ่ง (Dwell Period) ระหว่างการหมุน และจานตามถูกล็อกไว้ในช่วงนี้
3. กำหนดมุมหมุนต่อขั้นและจำนวนตำแหน่งหยุดได้จากจำนวนร่องของจานตาม
4. โครงสร้างไม่ซับซ้อน มีชิ้นส่วนหลักไม่มาก
5. กำหนดจังหวะการเคลื่อนที่ได้โดยไม่ต้องใช้ระบบควบคุมอิเล็กทรอนิกส์

**ตัวอย่างการใช้งาน:** เครื่องฉายภาพยนตร์แบบฟิล์ม, เครื่องจักรประกอบชิ้นงาน, เครื่องจักรบรรจุภัณฑ์

**ข้อจำกัด:** ไม่เหมาะกับความเร็วรอบสูง เกิดการสั่นสะเทือนและเสียงดังเมื่อทำงานเร็ว และหมุดกับร่องสึกหรอจากการเสียดสีและแรงกระแทก

## การวิเคราะห์ทางจลนศาสตร์

- **ประเภทการเคลื่อนที่:** Intermittent Rotary Motion
- **Input:** จานขับ (link 2) | **Output:** จานตาม (link 3)

| รายการ | ค่า |
|---|---|
| จำนวน link (L) | 3 |
| Full joints (J₁) — revolute ที่ O₂, O₃ | 2 |
| Half joints (J₂) — pin-slot ที่ A | 1 |

```text
DOF = 3(L − 1) − 2(J1) − 1(J2)
DOF = 3(3 − 1) − 2(2) − 1(1)
DOF = 1
```

DOF = 1 หมายความว่ากลไกเคลื่อนที่ได้เพียงรูปแบบเดียว คือการหมุนเป็นจังหวะของ link 3 เมื่อให้ input ที่ link 2

## องค์ประกอบของกลไก

| Link | ชื่อ | หน้าที่ |
|---|---|---|
| 1 | Ground (ฐาน) | ยึดอยู่กับที่ เป็นจุดเชื่อมของ link อื่น |
| 2 | Driver wheel (จานขับ) | ยึดกับ ground ที่ O₂ มีหมุดขับ เชื่อมต่อกับ link 3 |
| 3 | Geneva wheel (จานตาม) | ยึดกับ ground ที่ O₃ รับการถ่ายทอดการเคลื่อนที่จากจานขับ (5 ร่อง) |

## สมการควบคุม (Symbolic Mathematics)

**ตัวแปรและพารามิเตอร์**

| สัญลักษณ์ | ความหมาย | ค่า |
|---|---|---|
| θ | มุมหมุนของจานขับ (ทวนเข็มนาฬิกา) | rad |
| ω_in | ความเร็วเชิงมุมของจานขับ | 1 rad/s |
| N | จำนวนร่องของจานตาม | 5 |
| R | รัศมีของจานขับ | 25 mm |
| d | ระยะห่างระหว่างศูนย์กลางจานขับกับจานตาม | 43.441 mm |
| m | อัตราส่วนทางเรขาคณิต = d / R | — |
| β_out | ตำแหน่งเชิงมุมของจานตาม | rad |

**1) ตำแหน่งเชิงมุม**

```text
tan β = sin θ / (m − cos θ)
```

**2) ความเร็วเชิงมุม** (ใช้ Chain Rule)

```text
ω_out = (dβ/dθ) · ω_in = [ (m·cos θ − 1) / (m² − 2m·cos θ + 1) ] · ω_in
```

**3) ความเร่งเชิงมุม**

```text
α_out = (dω_out/dθ) · ω_in = [ −m(m² − 1)·sin θ / (m² − 2m·cos θ + 1)² ] · ω_in²
```
**ผลที่ได้จากการวิเคราะห์**

- ช่วงขบกัน θ ∈ [−0.942, +0.942] rad (±54°) คิดเป็น **30% ของรอบ** ที่เหลือ 70% เป็นช่วงหยุดนิ่ง (Dwell)
- จานตามกวาดมุม β จาก −0.613 ถึง +0.613 rad รวม **72° (≈ 1.257 rad) ต่อจังหวะ**
- ความเร็วเชิงมุมสูงสุดของจานตาม ≈ **1.356 rad/s** ที่ θ = 0 (กึ่งกลางการขบกัน)
- ความเร่งเชิงมุม**กระโดดจาก 0 เป็น ±0.727 rad/s²** ทันทีที่จุดเริ่มและจุดสิ้นสุดการขบกัน และสูงสุดประมาณ ±2.13 rad/s² ที่ θ ≈ ∓18.2° ทำให้เกิด **Infinite Jerk** ซึ่งเป็นสาเหตุของแรงกระแทกและการสั่นสะเทือน
-

**การจำลอง 2 มิติใน MATLAB**

1. สร้างโปรไฟล์ร่องแรก (`data0`) แล้วใช้เมทริกซ์การหมุน `Rot(theta)` คัดลอกให้ครบ 5 ร่อง ห่างกันร่องละ 72°
2. สร้างเส้นรอบวงนอก (R_wheel = 31.572 mm) ตัดกับวงกลมล็อก (sR = 19.867 mm) เพื่อสร้างส่วนเว้าสำหรับล็อกจานตามในช่วง Dwell
3. ออกแบบจานขับรูปหยดน้ำ (R₁ = 21.667 mm, R₂ = 3.333 mm) พร้อมตำแหน่งหมุดและแผ่นตัดส่วนโค้ง
4. จำลองการขบกันและการหมุนของกลไกทั้งชุด

## การออกแบบ CAD และต้นแบบ (Fusion 360)
<img width="453" height="367" alt="image" src="https://github.com/user-attachments/assets/616223df-98ab-45bc-8f12-c255b6c9d1e5" />

ขั้นตอนการทำงาน

1. **Sketch** ร่างภาพ 2 มิติของจานขับ จานตาม (5 ร่อง) และฐาน
2. **3D Modeling** ใช้ `extrude` ขึ้นรูป ทำหมุดให้สูงกว่าชิ้นส่วนอื่นเพื่อใช้จับ และเพิ่ม groove ที่ joint บนฐานสำหรับแหวนล็อก (retaining ring)
3. **Assembly** ประกอบด้วยคำสั่ง `joint`
4. **Animation** ใช้ `Animate joint relationships` ตรวจสอบการขัดกัน (interference)
5. **เตรียมผลิต** ใช้ `offset` กำหนดระยะเผื่อ (clearance) เพื่อลดการเสียดสีเมื่อประกอบและเคลื่อนที่

**Prototype:** พิมพ์ด้วย 3D printer เมื่อประกอบแล้วขยับได้ทันที แทบไม่มีการขัดกันของกลไก

## การจำลองด้วย Simscape Multibody

<img width="787" height="335" alt="image" src="https://github.com/user-attachments/assets/443fd822-1c78-4abe-b3db-ea070a80ef4a" />


### 1. เตรียมไฟล์ CAD

ส่งออกไฟล์ **STEP** จาก Fusion 360 ได้แก่ จานขับ, จานตามแบ่งเป็น 5 ชิ้นตามส่วนโค้ง, หมุดขับ และฐาน

### 2. การตั้งค่าโมเดล (Model Settings)

| พารามิเตอร์ | ค่า |
|---|---|
| Solver type | Variable-step |
| Solver | `ode23t` |
| Max step size | `1e-3` |
| Stop time | 50 s (ช่วงตรวจสอบเบื้องต้น 8–10 s) |

### 3. โครงสร้างโมเดล

- **Link 1 (Ground) Layout** — Subsystem ที่นำเข้าฐานด้วย File Solid และใช้ Rigid Transform กำหนดกรอบอ้างอิง มี 3 พอร์ต (Base Rigid Transform, Driven Joint, Driver Joint)
- **Link 2 (Driver Wheel) + Driver Joint** — Revolute Joint โดย Motion = *Provided by Input*, Torque = *Automatically Computed* ขับด้วย Ramp Input (slope = 1, start = 0) ผ่าน Simulink-PS Converter (หน่วย rad)
- **Pin** — ติดตั้งผ่าน Rigid Transform จากกรอบ F2 ของจานขับ และส่ง Geometry ไปคำนวณแรงสัมผัส
- **Link 3 (Geneva Wheel) Contact** — จานตาม 5 ชิ้น (Geneva1–5) ใช้ origin ร่วมกันและเคลื่อนที่เป็นวัตถุแข็งเกร็งเดียว โดยแต่ละชิ้นมี Spatial Contact Force คู่กับหมุด
- **Driven Joint** — Revolute Joint โดย Motion = *Automatically Computed*, Torque = *None* ปล่อยให้จานตามหมุนอิสระจากแรงสัมผัสระหว่างหมุดกับผนังร่อง

### 4. พารามิเตอร์แรงสัมผัส (ใช้ค่าเดียวกันทั้ง 5 บล็อก)

| รายการ | ค่า |
|---|---|
| Normal Force Method | Smooth Spring-Damper |
| Stiffness | 1e5 N/m |
| Damping | 50 N/(m/s) |
| Transition Region Width | 1e-4 m |
| Frictional Force Method | Smooth Stick Slip |
| Coefficient of Static Friction | 0.15 |
| Coefficient of Dynamic Friction | 0.1 |
| Critical Velocity | 1e-3 m/s |

### 5. เหตุผลที่เลือกใช้ Spatial Contact Force

ถ้ากำหนดการเคลื่อนที่ของจานตามโดยตรง จะต้องเขียนสมการการเคลื่อนที่และเงื่อนไขสลับสถานะระหว่างช่วง Indexing กับ Dwell รวมถึงสลับข้อกำหนดการเชื่อมต่อระหว่างชิ้นส่วน ซึ่งซับซ้อน การใช้แรงสัมผัสทำให้จานตามหมุนเมื่อหมุดเข้าร่อง และหยุดเมื่อหมุดออกจากร่องเอง ลดความซับซ้อนของแบบจำลอง

### 6. การตั้งค่าเริ่มต้นและการตรวจสอบ

- ปรับตำแหน่งเชิงมุมของจานตามให้ร่องหนึ่งอยู่ในแนวเส้นผ่านจุดศูนย์กลาง (ภายใน ±36°) และไม่ให้ชิ้นส่วนซ้อนทับกัน
- ตั้งมุมเริ่มต้นของจานขับให้หมุดอยู่ก่อนเข้าร่องประมาณ 20–30°
- ตรวจจาก Front View ว่าหมุดอยู่ระดับเดียวกับความหนาของจานตาม
- ผลที่ถูกต้องควรเป็น: จานขับหมุนต่อเนื่อง, จานตามหมุน 72° ต่อรอบของจานขับ และหยุดนิ่งในช่วงที่จานล็อกทำงาน

> 💡 หากจานตามไม่หมุนตามหรือเคลื่อนที่ผิดจังหวะ อาจเกิดจากข้อจำกัดของ Spatial Contact Force กับพื้นผิวเว้า แนวทางแก้ไขคือแยกหมุดและผนังร่องเป็นชิ้นส่วนนูน หรือเปลี่ยนให้ Driven Joint เป็น *Provided by Input* ตามสมการของกลไก Geneva

## ผลการศึกษา

เปรียบเทียบค่าจากทฤษฎีกับค่าจากการจำลองใน Simscape Multibody (r = 21.96 mm, a = 43.44 mm, λ = r/a)

| พารามิเตอร์ | ค่าจากทฤษฎี | ค่าจากการจำลอง | ความคาดเคลื่อน (%) |
|---|---|---|---|
| มุมหมุนต่อขั้น (องศา) | 72 | 70.1 | 2.64 |
| สัดส่วนเวลาเคลื่อนที่ | 0.588 | 0.506 | 13.95 |
| อัตราส่วนความเร็วเชิงมุมสูงสุด | 1.23 | 1.35 | 9.76 |

**สรุป:** แบบจำลองแสดงพฤติกรรมการหมุนเป็นจังหวะของกลไก Geneva ได้ตามหลักการพื้นฐาน ความคลาดเคลื่อนน่าจะเกี่ยวข้องกับพารามิเตอร์แรงสัมผัส (stiffness, damping, friction) และการกำหนดรูปทรงและเงื่อนไขการสัมผัส

## ข้อจำกัดของแบบจำลอง

- ประมาณรูปทรงจานตามด้วยชิ้นส่วนนูน (Convex Hull) 5 ชิ้น ตามข้อกำหนดของบล็อกแรงสัมผัส
- สมมติให้ชิ้นส่วนเป็นวัตถุแข็งเกร็ง
- พารามิเตอร์แรงสัมผัสยังไม่ได้สอบเทียบกับวัสดุจริง
- ยังไม่ได้เปรียบเทียบกับผลการทดลองจากต้นแบบ

## ข้อเสนอแนะ

1. **วัสดุและการผลิต:** เลือกวัสดุที่แข็งแรงและทนการสึกหรอบริเวณหมุดและร่อง สำหรับงาน 3D printing ควรคำนึงถึงความแม่นยำของขนาดและกำหนด clearance ให้เหมาะสม
2. **การออกแบบ:** ศึกษาการปรับรูปทรงร่องและจานขับ รวมถึงปรับความเร็วรอบ เพื่อลดแรงกระแทกและการสั่นสะเทือนจากความเร่งที่เปลี่ยนอย่างฉับพลัน
3. **การจำลองและทดสอบ:** ขยายการจำลองให้ครอบคลุมทั้งจลนศาสตร์และพลศาสตร์ เปรียบเทียบผลเชิงสัญลักษณ์และ MATLAB กับต้นแบบจริง และทดสอบที่ความเร็วรอบต่าง ๆ
4. **การสอบเทียบ:** วัดสัมประสิทธิ์แรงเสียดทานและความแข็งเกร็งของพลาสติกที่ใช้จริง แล้วนำมาปรับพารามิเตอร์ของแบบจำลอง
